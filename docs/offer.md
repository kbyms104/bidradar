# 입찰 공고 모니터링 — 가격·제공 범위

첫 고객을 위한 기준안입니다. 상담하면서 플랜만 조정하고, 기능 범위는 그대로 안내하세요.

- 라이브 데모: <https://bidradar-kr.duckdns.org/demo>
- 고객 콘솔: <https://bidradar-kr.duckdns.org/login>
- 상담 신청: <https://bidradar-kr.duckdns.org/#contact>

## 대상

- 입찰 담당자가 따로 없는 중소 SI·건설·제조·용역 회사 (10~100명)
- 나라장터와 지자체 사이트를 매일 직접 확인하는 곳
- 공고를 놓쳐 입찰 기회를 잃은 경험이 있는 곳

## 제공 범위

| 구분 | 내용 |
|---|---|
| 수집 | 나라장터 공고(지자체·공공기관 게시분 포함), 15분 주기 |
| 화면 | 웹 대시보드 — 내 조건에 맞는 공고만 표시, 모바일 반응형 |
| 필터 | 키워드, 제외 키워드, 지역, 분야, 최소 금액, 마감기간 |
| 알림 | 디스코드 웹훅으로 마감 D-3 / D-1 자동 발송, 원문 링크 포함 |
| 이력 | 알림 발송 이력(성공·실패·건수) 콘솔에서 확인 |
| 리포트 | 주간 마감 요약 (요일별·분야별) |
| 계정 | 고객별 로그인·조건·웹훅 분리 (멀티테넌트) |

**SI 구축이 아니라 가입형 서비스입니다.** 초대 코드로 계정을 만들고, 조건과 디스코드 웹훅을 저장하면
그날부터 알림이 발송됩니다. 별도 설치·서버·교육이 필요 없습니다.

## 가격

| 플랜 | 월 이용료 | 알림 조건 | 비고 |
|---|---:|---:|---|
| 파일럿 (선착순 2곳) | 19만원 | 3개 | 3개월 후 정가 전환, 사례 공개 동의 |
| Basic | 29만원 | 3개 | 콘솔·디스코드 알림·이력 |
| Pro | 49만원 | 10개 | Basic + 주간 리포트 우선 지원 |

- 월 이용료는 **3개월 단위 선결제**를 기본으로 합니다. (첫 결제 후 3개월 유지)
- 파일럿은 첫 달 후 해지 가능. 이후 월 단위.
- 부가세 포함 여부는 계약 시 명시합니다. (사업자등록 전에는 세금계산서 발행 불가 — 부가세법상 간이과세/면세 여부 확인 필요)
- 입금 계좌·계약서는 첫 상담 후 발송합니다.

## 고객이 준비할 것

- 관심 키워드 10~20개 (예: "AI", "CCTV", "상수도", "유지관리")
- 주력 지역과 분야
- 알림 받을 **디스코드 채널**과 웹훅 URL
  (채널 → 채널 편집 → 연동 → 웹훅 → 새 웹훅 → URL 복사)
- 공고 원문 확인용 담당자 1명

세팅은 10분입니다. 고객이 직접 `/login`에서 조건과 웹훅을 저장하고 `테스트 발송`으로 확인하면 끝입니다.
운영자가 대신 세팅해 줄 경우 초대 코드만 전달하고 화면 공유로 10분 안에 마무리합니다.

## 영업 시 강조점

1. **"공고를 더 보여주는 게 아니라, 볼 것만 보여줍니다."**
   전체 공고 수를 자랑하지 말고 검색 시간을 줄여주는 데 집중합니다.
2. **"놓치면 매출 0, 잡으면 수천만 원."**
   월 29만원은 공고 1건만 더 따도 회수됩니다.
3. **"오늘 가입하면 오늘 알림이 옵니다."**
   구축 기간 2주가 아니라, 조건 저장 → 테스트 발송 → 다음 발송 시각(09:00 / 17:00)부터입니다.
4. **"내 조건 밖 공고는 보내지 않습니다."**
   키워드·지역·금액·제외어를 그대로 반영하고, 알림 이력으로 실제 발송을 확인할 수 있습니다.

## 첫 연락 문구

> 안녕하세요. 입찰 공고 때문에 매일 나라장터와 지자체 사이트를 돌고 계신가요?
> 키워드와 지역만 등록하면 조건에 맞는 공고만 디스코드로 보내드리는
> 모니터링 서비스를 운영하고 있습니다. 웹에서 조건 저장하고 테스트 알림까지
> 10분이면 확인하실 수 있습니다. 지금 어떻게 공고를 찾고 계신지 10분만
> 이야기해 주실 수 있을까요?

## 피해야 할 표현

- "자동 입찰", "낙찰 보장", "수익 보장" — 과장·오해 소지
- "전국 모든 공고 100% 수집" — 누락 가능성
- "AI가 알아서 다 해줍니다" — 실제 범위는 조건 매칭과 알림
- "세금계산서 발행" — 사업자등록 전에는 불가. 필요하면 사업자등록 후 안내
