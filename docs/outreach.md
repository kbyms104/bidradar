# 첫 고객 20곳 아웃리치 계획

목표: **6개월 안에 유료 고객 6~10곳** (월 19~49만원 → 월 300만원).
첫 2주는 20곳에게 직접 연락해 **파일럿 2곳**을 만드는 것이 목표입니다.

- 데모: <https://bidradar-kr.duckdns.org/demo>
- 고객 콘솔: <https://bidradar-kr.duckdns.org/login>
- 상담 폼: <https://bidradar-kr.duckdns.org/#contact>

## 0. 어디서부터? (성공률 순서)

콜드 연락부터 시작하면 대부분 지칩니다. 아래 순서로 하세요.

**1순위 — 아는 회사 (1주 안에 파일럿 가능)**

머릿속으로 다음을 한 번씩 훑어보세요. 10곳이면 충분합니다.

- 전 직장 동료·상사가 다니는 회사
- 친척·친구가 운영하거나 다니는 회사
- 거래처, 협력업체, 동네에서 아는 사장님
- 고등학교·대학 동기 중 회사 다니는 사람

"혹시 회사에서 나라장터 입찰 보나요?" 한마디면 됩니다. 입찰을 본다면 그 자리에서
데모를 보여주고 초대 코드를 주면 끝입니다. **첫 파일럿 2곳은 여기서 나오는 경우가 대부분입니다.**

**2순위 — 입찰대행·컨설팅 업체 (한 번에 여러 고객)**

입찰대행사는 이미 중소기업 고객 10~50곳을 가지고 있고, 그 고객들의 공고를 매일 찾아줍니다.
우리 서비스를 그 업체가 고객에게 붙여주면, 한 번의 제안으로 여러 곳에 들어갑니다.

- 검색: "입찰대행", "입찰컨설팅", "나라장터 대행" + 지역명
- 제안: "고객사에 알림 서비스를 제공하세요. 월 이용료의 20% 소개 수수료"
- 대표님·실장님께 전화하거나, 홈페이지 문의로 위 내용을 보내면 됩니다

**3순위 — 낙찰정보로 콜드 연락 (아래 2번 방법)**

1·2순위가 막히면 여기로 오세요. 20곳 중 1~2곳이 파일럿이 되면 정상입니다.

## 1. 누구에게 연락할까

**맞는 곳**

- 임직원 10~100명, 입찰 담당자가 1명이거나 겸직인 회사
- 최근 3개월 안에 나라장터에서 **2건 이상** 입찰/낙찰 기록이 있는 회사
- 우리 지역·분야(소프트웨어/SI, 시설·유지관리, 용역, 전기·통신)에 반복해서 나오는 회사
- 공고를 놓친 경험이 있거나, 담당자가 퇴사해 인수인계가 안 된 회사

**피할 곳**

- 입찰 전담 조직이 있는 대기업·중견 건설사 (이미 시스템이 있음)
- 최근 1년 입찰 기록이 없는 회사
- 개인사업자·1인 회사 (월 29만원 지불 여력이 어려움)

## 2. 20곳을 모으는 방법 (2시간)

1. **나라장터 낙찰정보**에서 최근 3개월, 관심 분야로 검색 → 낙찰 업체명 30개를 적습니다.
   - <https://www.g2b.go.kr> → 입찰정보 → 낙찰정보
2. 각 업체 홈페이지의 **문의·오시는 길**에서 대표 전화/이메일을 확인합니다.
   - 대표 메일이 없으면 `대표전화`로 걸어 "입찰 담당자"를 요청합니다.
3. 아래 표에 20곳을 채웁니다. (분야·지역·최근 낙찰 1건·연락 채널)

> 연락처는 공개된 회사 대표 채널만 사용합니다. 개인 휴대폰·개인 메일을 수집·판매하지 않습니다.

## 5. 후속 연락 (이게 매출을 만듭니다)

| 시점 | 내용 |
|---|---|
| D+0 | 첫 연락 (이메일 또는 전화) |
| D+2 | 같은 스레드에 "데모 링크 + 1문장" 리마인드 |
| D+5 | 다른 채널(전화→메일)로 1회 |
| D+10 | 마지막: "필요하실 때 쓰시라고" 초대 코드 1개 + 종료 인사 |
| 이후 | 분기 1회, 새 기능/사례 중심으로 재연락 |

- 답장이 없어도 **3회까지**는 정중하게 팔로우업합니다.
- 거절하면 이유를 한 줄 적고, 6개월 뒤 다시 연락할 목록으로 옮깁니다.

## 6. 통화에서 확인할 것 (5문항)

1. 지금 공고를 어디서, 하루 몇 분씩 확인하나요?
2. 최근에 놓친 공고가 있나요? (있다면 어떤 공고였나요?)
3. 주로 나가는 지역·분야·금액대는 어디인가요?
4. 디스코드를 쓰고 있나요? 안 쓴다면 어떤 채널을 쓰나요?
5. 월 19~29만원이면, 공고 1건을 더 따는 걸로 회수된다고 보시나요?

→ 3번 답변을 그 자리에서 조건으로 만들어 **테스트 알림**까지 보내주면 전환율이 가장 높습니다.

## 7. 데모 → 파일럿 전환

1. 통화 중 고객 조건 2~3개를 받아 적습니다.
2. `python3 provision.py invite --note "A사"`로 초대 코드 발급.
3. 고객에게 코드와 `/login` 링크를 보내고, 화면 공유로 10분 세팅.
4. 조건 저장 → 디스코드 웹훅 연결 → **테스트 발송** → 고객 채널에 메시지 도착 확인.
5. "내일 09:00부터 실제 알림이 갑니다"로 마무리.
6. 3일 뒤 "알림 잘 오고 있는지" 확인 전화 → 3개월 결제 요청.

### 고객에게 보내는 세팅 안내 (복사용)

> 안녕하세요, ○○ 담당자님. BidRadar 초대 코드 보내드립니다.
>
> **초대 코드: `XXXXXXXX`**
>
> 1. https://bidradar-kr.duckdns.org/login 접속 → **시작하기** 탭
> 2. 이메일·비밀번호(8자 이상)·회사명·담당자명 + 위 초대 코드 입력
> 3. 자동으로 **알림 설정** 화면이 열립니다
> 4. **알림 조건**에 키워드(예: CCTV, 유지관리)와 지역을 넣고 저장
> 5. **디스코드 웹훅**에 채널 웹훅 URL을 붙여넣고 **저장 → 테스트 발송**
> 6. 디스코드 채널에 테스트 메시지가 오면 끝입니다
>
> 웹훅 URL은 디스코드에서 이렇게 확인합니다:
> 채널 이름 우클릭 → 채널 편집 → 연동 → 웹훅 → 새 웹훅 → URL 복사
>
> 세팅 후 **다음 발송 시각(09:00 / 17:00)**부터 마감 D-3·D-1 공고가 자동으로 갑니다.
> 화면이 안 되거나 조건을 못 정하시면 말씀해 주세요. 화면 공유로 10분 안에 같이 세팅해 드립니다.
>
> 이용약관: https://bidradar-kr.duckdns.org/terms
> 개인정보처리방침: https://bidradar-kr.duckdns.org/privacy

- 초대 코드는 **1회용**입니다. 고객이 가입하면 자동으로 무효가 되니, 재사용이 필요하면 새로 발급하세요.
- 코드를 메일로 보낼 때는 **본문에만** 쓰고, 여러 명이 보는 단체 채널에는 올리지 마세요.

## 8. 파트너 채널 (추천)

직접 20곳을 뚫는 것보다, 이미 중소기업 고객을 가진 곳과 제휴하면 1건이 여러 건이 됩니다.

| 파트너 유형 | 왜 맞나 | 제안 |
|---|---|---|
| 입찰 컨설팅·입찰대행 업체 | 고객의 공고 탐색을 대신 해주고 있음 | 고객사에 BidRadar 알림 제공, 월 이용료의 20% 소개 수수료 |
| 지역 IT·SI 협회/조합 | 회원사 대부분이 입찰을 봄 | 회원사 대상 1회 웨비나 + 파일럿 할인 코드 |
| 상공회의소·창업지원센터 | 교육·상담 프로그램에 넣기 좋음 | "입찰 공고 놓치지 않기" 30분 교육 + 데모 링크 |
| 노무·세무·회계 사무소 | 거래처 대표와 직접 연결됨 | 소개 카드, 첫 달 무료 체험 코드 |

- 파트너에게는 **고객 개인정보를 넘기지 않습니다.** 소개 코드만 발급하고, 가입·결제는 고객이 직접 합니다.
- 첫 파트너 1곳과 계약하면, 그 채널에서 매달 1~2건이 나오는지 3개월간 확인합니다.

## 9. 주간 목표

| 주차 | 활동 | 목표 |
|---|---|---|
| 1주 | 20곳 리스트 작성, 10곳 첫 연락 | 통화 3건 |
| 2주 | 나머지 10곳 연락, 팔로우업 | 데모 3건, 파일럿 1건 |
| 3주 | 파일럿 세팅, 사례 1건 정리 | 파일럿 2건 |
| 4주 | 소개 요청, 2차 리스트 20곳 | 결제 1건 |

> 20곳 중 2곳이 파일럿이 되면 성공입니다. 100곳을 뿌리는 것보다, 20곳을 끝까지 팔로우업하는 편이 낫습니다.

## 10. 첫 결제 전에 확인할 것

- **사업자등록**: B2B 고객은 세금계산서를 요구하는 경우가 많습니다. 첫 유료 계약이 가까워지면 간이과세자로 등록하는 편이 안전합니다. (등록 전에는 계좌이체·현금영수증으로 안내)
- **계약서**: 월 이용료, 3개월 기간, 해지·환불, 정보 제공 범위(낙찰 보장 없음)를 한 장으로 정리해 보냅니다.
- **개인정보**: 고객 담당자 연락처는 상담 목적만 사용하고, 요청 시 삭제합니다. `/privacy` 링크를 메일 하단에 붙입니다.
- **디스코드 웹훅**: 고객이 만든 채널의 웹훅을 받아 저장합니다. 고객에게 우리 서버의 웹훅을 공유하지 않습니다.
